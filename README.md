# MedHub 🩺

Платформа для студентов-медиков: учёба, справочники, симуляторы, тренажёры и клинический дневник группы. Интерфейс на трёх языках (RU / UZ / EN), три темы (светлая, тёмная, ночная для дежурств).

## Возможности

**I. Академический блок**
- Дашборд успеваемости: оценки, GPA, динамика по 6 курсам, экспорт в Excel
- Календарь и дедлайны: лекции, коллоквиумы, зачёты, экзамены, дежурства + обратный отсчёт
- Групповой банк материалов: конспекты, методички, ссылки (общая лента группы)
- Лента типичных ошибок потока: вопрос → неверный ответ → правильный → разбор

**II. Умный медицинский поиск**
- Сквозной поиск: библиотека платформы + личные заметки + интернет
- Фильтры по типу контента: учебники / статьи и гайдлайны / шпаргалки / видео (проверенные источники: PubMed, Cochrane, Scholar)

**III. Справочно-информационный модуль**
- МКБ-10 (~700 кодов, все главы) + структура МКБ-11
- Фармакологический справочник (~78 действующих веществ): показания, дозы, противопоказания, взаимодействия, беременность
- Лабораторные нормы (~80 показателей): ОАК, биохимия, гормоны, моча, ликвор, коагулограмма — по полу и возрасту
- Клинические протоколы (12): анафилаксия, ОКС, ТЭЛА, отёк лёгких, гипертонический криз, ДКА, ОНМК и др.
- 17 медицинских калькуляторов: CKD-EPI, Cockcroft-Gault, ИМТ, GCS, Wells, CHA₂DS₂-VASc, CURB-65, MAP, анионная щель, QTc и др.

**IV. Симуляторы**
- Интерактивная карта боли: реальное 3D-тело человека с внутренностями, мужская / женская / педиатрическая анатомия, 28 кликабельных зон (органы, причины, иррадиация, красные флаги) + галерея 3D-анатомии
- Аускультация: 15 звуков сердца, лёгких и живота, синтезируются WebAudio, точки прослушивания на теле
- ЭКГ-симулятор: 14 ритмов (норма, ФП, блокады, ЖТ, STEMI, гиперкалиемия…), рисование в реальном времени + пошаговый разбор + режим теста
- Атлас визуальной диагностики: настоящие снимки — рентген, КТ, МРТ, гистология, глазное дно, отоскопия (схемы как запасной вариант)

**V. Тренажёры**
- Генератор случайного пациента: 19 кейсов (жалобы + витальные + аускультация + ЭКГ + анализы + карта боли) с проверкой диагноза и разбором
- Тестовый банк: 60 вопросов по 9 предметам + режим экзамена (20 вопросов, 25 минут)
- Flash-карточки с интервальным повторением (SRS), стартовая колода + свои карточки, серия дней

**VI. Клинический дневник и совместная практика**
- Дневник курации (обезличенные карточки пациентов), экспорт в PDF/Excel
- Чек-лист навыков (34 манипуляции): наблюдал → под контролем → сам
- Реестр операций (наблюдатель/ассистент)
- Кейсы группы: закрытая лента с комментариями
- Дневник рефлексии: ситуация → ошибка → урок → темы для повторения (одним кликом в карточки)
- График дежурств: смены, часы, заявки на подмену в ленту группы

**VII. Настройки**
- Языки RU/UZ/EN, группы по коду с ролями (админ/студент)
- Темы, латинская терминология, качество графики
- Офлайн-режим (все базы встроены), резервная копия JSON, синхронизация по ключу
- Уведомления о дежурствах, коллоквиумах и карточках

## Запуск локально

```bash
cd MedHub
npm install
npm start          # http://localhost:3000
```

## Деплой на Render

### Вариант А — статический сайт (проще всего)

`render.yaml` уже настроен на `runtime: static`:

1. https://dashboard.render.com → **New → Blueprint** → выбрать репозиторий
2. Render возьмёт файлы из `public/` → **Apply**
3. Сайт на `https://medhub.onrender.com`, каждый push в main передеплоивается сам

В статическом режиме всё работает офлайн-механиками: справочники, симуляторы,
тренажёры, дневник, экспорт — полностью. Группы, общие ленты и облачная
синхронизация хранятся локально в браузере (приложение само определяет режим
и пишет об этом в «Настройки → Язык и группа»).

### Вариант Б — Node-версия (группы работают между устройствами)

```bash
# локально
npm install && npm start        # http://localhost:3000
```

На Render: создайте Web Service вручную (Environment: Node,
Build `npm install`, Start `npm start`) или временно замените `render.yaml`
на Node-конфигурацию:

```yaml
services:
  - type: web
    name: medhub
    runtime: node
    plan: free
    buildCommand: npm install
    startCommand: npm start
```

Клиент сам определяет наличие API (`/api/health`) и переключается на серверный режим без изменений в коде.

## Технологии

- **Сервер:** Node.js + Express, JSON-файл как БД (группы, ленты, резервные копии) — единственная зависимость — express
- **Клиент:** ванильный JS SPA (i18n, темы, localStorage + серверная синхронизация), SVG-анатомия, Canvas (ЭКГ, атлас), WebAudio (аускультация)
- **Данные:** все справочники встроены в бандл — полностью работает офлайн

## Важно

Учебный проект. Справочные данные упрощены и не заменяют официальные инструкции, протоколы и клинические рекомендации. Снимки атласа и 3D-модели анатомии — реальные изображения из открытых источников (LITFL, MedSchool, PMC/NIH, Geeky Medics, TeachMeSurgery, AMBOSS, Innerbody, Sketchfab и др.), принадлежат их правообладателям и используются в учебных целях; часть схем — обучающие иллюстрации.
